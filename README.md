# 产品召回助手（product-recall）

面向 **质量总监 / 合规** 的技能：规范产品召回的触发判定、分级、通知矩阵与演练推演，自动生成召回预案与模拟推演表，输出 **纯文字版(.txt) + Markdown(.md)**。

## 适用角色

- 质量总监
- 合规 / 法规事务

## 使用方式

```bash
# 使用内置小样本（首次跑通验证）
python scripts/build_report.py --out-dir ./out

# 使用自有数据
python scripts/build_report.py --input recall.json --out-dir ./out
```

## 输入字段（摘要）

- `meta`：产品、批次、企业、日期、负责人。
- `recall`：触发原因、风险等级(一/二/三级)、预估数量、影响区域、根因。
- `notifications[]`：渠道、告知方式、时限、责任方。
- `timeline[]`：里程碑、时限、动作。
- `drill[]`：演练场景、参与角色、时长、检查点。

## 召回分级（通用参考，企业可覆盖）

| 等级 | 风险 | 范围 | 启动 | 公告 |
|------|------|------|------|------|
| 一级 | 安全/法规重大 | 全国 | 立即 | 媒体公告 |
| 二级 | 较大 | 限定区域 | 限期 | 定向通知 |
| 三级 | 一般 | 特定批次/渠道 | 渠道内 | 渠道回收 |

## 防幻觉声明

法规条款号、监管时限、根因结论缺失时标「待企业补充」；分级默认参考通用矩阵，非强制标准，最终以企业制度与所在地法规为准。
